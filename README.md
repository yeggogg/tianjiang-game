# 《天降一掌》 (Tianjiang)

单文件 HTML5 竖屏动作肉鸽小游戏，零外部依赖，开箱即玩。

- **在线试玩（GitHub Pages）**：https://yeggogg.github.io/tianjiang-game/
- **最新版本**：**V2.9** (`tianjiang_V2.9.html` / `index.html`)

## V2.9 核心更新
- **P1 操法得分平衡**：高频连续命中点按动态延长断连宽限至最高 `4.5s`；连击倍率曲线前期加速、后期 `2.65x` 平滑封顶；命中率加成 `72%` 封顶，缩小点按与满蓄分差。
- **P1 统一流派增伤与冰封小成修复**：小成 `1.15x` / 大成 `1.30x` 单一来源并在扣护盾前统一乘算，补全冰/火/神掌全派生与基础落掌/蓄力映射，对齐烈焰流派名「烈焰蔓延」，支持同系 3 张或累计 ≥6 级激活小成（修复寒冰掌×3+冰棱领域×3 不出小成问题）。
- **P1 全源单步 6 只预算与防神掌自循环**：分裂子体纳入 `maxPerStep = 6` 单步预算（超额进入 `pendingSpawnQueue` 顺延释放）；神掌回能仅计核心卡（上限 3 张，排除填充卡）、单卡比例降至 `15%`、单次神掌回能硬上限 `24`（严格低于 `30` 消耗）。
- **P2 交互边界、引导与数据一致性**：1 档短蓄新增青金色击退波纹与首页 `1.05×` 说明；阻塞弹窗期间松手保留 `frozenCharge`；松手 65% 位移按 `dt` 限速防跳位；神掌新手引导气泡挂载进正常主帧循环；达成小成/大成在选卡瞬间即时提示，底栏 HUD 显示全部徽章；`105s` 起尾部精英保底入场（5 种子均稳定出齐 12 只精英）；「换一批」前 3 级复用 3 不同流派保底；雷霆 D 卡正式接入 `damageMul [0.55, 0.70, 0.85]` 与 `[3, 5, 7]` 目标；排行榜完整存储 5 项 `scoreBreakdown` 并严格校验全项非负与总和一致，修复空榜/损坏数据误报重置提示。
