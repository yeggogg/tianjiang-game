# 《天降一掌》 (Tianjiang)

单文件 HTML5 竖屏动作肉鸽小游戏，零外部依赖，开箱即玩。

- **在线试玩（GitHub Pages）**：https://yeggogg.github.io/tianjiang-game/
- **最新版本**：**V2.7** (`tianjiang_V2.7.html` / `index.html`)

## V2.7 核心更新
- **神掌计分口径与单次上限修复**：仅统计场内实际可命中（`hittable`）敌人数，屏外敌人与 0 命中空放得 `0` 分，单次上限 `600` 分（`110 + 命中数 × 25`），使神掌占比回归 7%–15% 合理区间。
- **雷印批次保护、里程碑单次结算与流派伤害全覆盖**：`dealAttack` 主循环外层锁定 `holdBatch/releaseBatch`，雷印死亡爆炸不再提前关闭主攻击多杀/靶心批次；`30/50/80` 连杀里程碑每局单次结算不重复刷分；流派小成/大成 `+15%` 伤害统一覆盖吸星、烈焰、冰封、雷霆、神掌及普通落掌/蓄力全路径。
- **蓄力平滑物理与真实时间戳**：中蓄微调至 `1.30x` 范围/`1.35x` 伤害/`0.42s` 冷却，满蓄微调至 `1.50x` 范围/`2.20x` 伤害/`0.80s` 冷却；蓄力减速改按 `dt` 平滑插值且松手不瞬移；蓄力按住时长结合真实时间戳封顶，防止卡顿追帧把短按误判为满蓄。
- **刷怪约束、出卡与工程收口**：固定出兵遵循当前难度档位同屏上限与单步最多 `6` 只补刷约束；持有闪电链后提升雷霆印记权重，点击「换一批」排除当前三张组合；排行榜与成就按版本键严格隔离；彻底默认关闭 `window.__TJ`（含 `fxInfo`）；接入 `perf.maxFrameDt`、清理死配置、合并开局重复挑战横幅、补全首页三档蓄力说明与标准 `rel="icon"`。
