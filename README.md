# 《天降一掌》 (Tianjiang)

单文件 HTML5 竖屏动作肉鸽小游戏，零外部依赖，开箱即玩。

- **在线试玩（GitHub Pages）**：https://yeggogg.github.io/tianjiang-game/
- **最新版本**：**V2.5** (`tianjiang_V2.5.html` / `index.html`)

## V2.5 核心更新
- **蓄力定位重构与代价**：移除满蓄固定 `+150` 分与额外 `+3` 能量，回调满蓄范围至 `1.55x`、伤害至 `2.2x`，增加满蓄后摇冷却 `0.78s` 与蓄力移速代价，保留满蓄必中会心与湮灭防分裂，让轻点/重掌/满蓄各有场景优势。
- **五大流派平衡与出卡保底**：前 3 次升级（Lv2–4）完全屏蔽填充卡并保底覆盖五大流派核心入门卡；单次三选一严格去重；4 级后填充卡权重降至 `35%`；所有卡面正面效果精简至 14 字以内；雷霆闪电链衰减提升至 `0.95`，雷印死亡必爆并向 2 名敌人传染；神掌单次分上调至 `180`，每张神掌技能扩大余震 `15%` 且直杀回能 `20%`；五大流派小成（`+600`）/宗师（`+1500`）在暂停与结算面板同步展示。
- **计分拆解与 C 级实战指引**：「生存通关」拆分为「基础通关奖 1,800」+「完好防线奖（满分 1,000，每漏 1 怪扣 50）」；结算 C 级时根据短板数据自动给出 1 条具体操作提示。
- **HUD 紧凑化与高频防卡死**：底栏技能改为单行图标 + `Lv.X` 徽章不折行；顶部挑战限 10 字以内并附 `⚡` 奖励徽章；暂停/设置页同步音效开关；补齐 `<link rel="shortcut icon">` 零 404；新增 50ms 高频输入节流与升级确认按钮防重入锁。
