# 《天降一掌》 (Tianjiang)

单文件 HTML5 竖屏动作肉鸽小游戏，零外部依赖，开箱即玩。

- **在线试玩（GitHub Pages）**：https://yeggogg.github.io/tianjiang-game/
- **最新版本**：**V2.8** (`tianjiang_V2.8.html` / `index.html`)

## V2.8 核心更新
- **P1 刷怪流控与评级重定**：统一读取 `state.pace.cap`（废弃失效的 `state.pace.maxEnemies`）；固定精英取消 `bypassEliteLimit` 并统一走 `canSpawnElite()` 校验（未满足条件时延后补刷不卡波次）；单次模拟步共享 `_stepSpawned <= 6` 限流；依据 V2.7 实测将 S/A/B 评级阈值校准为 `21,000 / 15,500 / 11,000`。
- **P2 伤害管线、状态修复与抽卡保护**：流派小成/大成 `+15%` 增伤改为按技能来源精准分流并在扣除护盾前统一乘算；达成小成/大成时弹出专属提示并在底部 HUD 常驻流派徽章；修复蓄力冻结恢复时累计时长被覆盖与松手落点丢失；限时挑战改为同帧先结算击杀再判定超时；「换一批」复用前 3 次升级流派分散保底，候选不足无法生成新组合时自动提示且不扣次数。
- **手势平衡与雷霆流补强**：点按冷却微调至 `0.33s`；一级短蓄（`0.18–0.44s`）增强至 `1.05x` 伤害/范围并新增 `28px` 轻度击退与 `0.46` 宽靶心判定；提升雷霆前期连锁伤害与持有闪电链后「雷霆印记」权重（`×8.5`）；赋予填充卡流派标签（掌风回旋→吸星、残影追掌→神掌、裂地冲击→烈焰）。
- **动态卡面、榜单校验与新手气泡**：升级卡面随等级动态显示下一级具体数值变化；补全首页四档蓄力说明（含中蓄 `0.42s` 冷却与 60Hz 约 `0.47s` 触发提示）及跨版本榜单重置提示；本地榜单新增分项之和与 `65,000` 上限轻校验；第 1 局前 30 秒神掌首次亮起时弹出非阻塞引导气泡。
