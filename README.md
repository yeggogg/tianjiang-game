# 《天降一掌》 (Tianjiang)

单文件 HTML5 竖屏动作肉鸽小游戏，零外部依赖，开箱即玩。

- **在线试玩（GitHub Pages）**：https://yeggogg.github.io/tianjiang-game/
- **最新版本**：**V2.9** (`tianjiang_V2.9.html` / `index.html`)

## V2.9 核心更新
- **操法得分平衡**：高频连续命中点按动态延长断连宽限至最高 `4.5s`；连击倍率曲线前期加速、后期平滑封顶至 `2.65x`；命中率加成设置 `72%` 封顶，拉近点按与满蓄的得分曲线。
- **统一流派增伤与冰封小成修复**：小成 `1.15x` / 大成 `1.30x` 统一单一计算来源并在扣护盾前乘算，补齐冰/火/神掌全派生及基础落掌/蓄力映射；对齐烈焰流派名「烈焰蔓延」；支持同系 3 张或累计 `≥ 6` 级触发小成。
- **全源单步预算与阻断神掌自循环**：分裂子体统一计入每步最多 `6` 只出生预算，超额推入队列顺延释放；神掌回能仅统计核心卡（上限 3 张，排除填充卡），单卡回能 `15%`，单次神掌回能硬上限 `24`。
- **交互边界、引导与数据一致性**：1 档短蓄新增青金色击退波纹反馈；阻塞弹窗期间松手保留 `frozenCharge`；松手 65% 位移按 `dt` 限速防跳位；神掌新手引导气泡挂载主帧循环；达成小成/大成即时提示并在底栏 HUD 完整展示全部流派徽章；`105s` 起尾部精英保底入场；「换一批」前 3 次升级复用 3 不同流派保底；雷霆 D 卡正式接入 `damageMul [0.55, 0.70, 0.85]` 与 `[3, 5, 7]` 目标，填充卡权重回调至 `0.55`；本地榜单完整存储 5 项 `scoreBreakdown` 并校验全项非负与总和一致。
