# 《天降一掌》 (Tianjiang)

单文件 HTML5 竖屏动作肉鸽小游戏，零外部依赖，开箱即玩。

- **在线试玩（GitHub Pages）**：https://yeggogg.github.io/tianjiang-game/
- **最新版本**：**V2.4** (`tianjiang_V2.4.html` / `index.html`)

## V2.4 核心更新
- **单轨综合分与结算重构**：首页最高分、HUD、结算与排行榜全部统一为 `TotalScore`，移除旧版冲突的「分数来源」区块，新增 **S/A/B/C** 评级徽章、下一档分差指引与常驻底部操作栏。
- **计分与流派共鸣增强**：精英/重甲/分裂基础分提升至 `150 / 35 / 35`，连击倍率上限提升至 `3.10x`，新增 `30/50/80` 连杀里程碑即时奖励；雷霆闪电链跳数增至 `[3, 5, 7]`（衰减 `0.88`）、雷印范围 `+20%`；神掌对精英/重甲伤害 `+25%`；新增同流派 `3/4` 张技能共鸣（流派小成 `+15% / +600分`、流派宗师 `-20% CD / +1500分`）。
- **卡池体验与核心节奏**：首次升级必出 3 张不同主流派核心技、新增每局 1 次「换一批」免费刷新、精简卡面；三档蓄力缩短为 `0.15s / 0.45s / 0.80s`（满蓄 `1.75×` 范围、`+150` 战斗分、`+3` 能量并阻止分裂怪分裂）；新增掌心 `40%`「正中靶心」、轻点冷却环与神掌清场加速出兵（总兵量恒定 360 只）。
- **视觉、音效与性能**：延续《超进化物语2》剪影美术包、防遮挡双层特效、16 组国风音效与 60 FPS 移动端深度优化，并修复 BUG-01~04。
