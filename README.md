# 《天降一掌》 (Tianjiang)

单文件 HTML5 竖屏动作肉鸽小游戏，零外部依赖，开箱即玩。

- **在线试玩（GitHub Pages）**：https://yeggogg.github.io/tianjiang-game/
- **最新版本**：**V2.6** (`tianjiang_V2.6.html` / `index.html`)

## V2.6 核心更新
- **蓄力冷却守恒与三档校准**：轻点/中蓄/满蓄出手前均检查 `palmCd` 且冷却单调不缩短；取消 `0.02s` 提前量，三档严格按 `0.18 / 0.45 / 0.80s` 判定，伤害 `1.00 / 1.25 / 2.00x`、范围 `1.00 / 1.25 / 1.45x`、冷却 `0.35 / 0.35 / 0.80s`；接入蓄力移速衰减（`0.65x`）；靶心统一要求内圈命中 `≥ 3` 敌（取消满蓄单体自动靶心）；2 档不再默认阻止分裂怪分裂。
- **雷霆印记与神掌计分修复**：修复一级雷霆印记死亡无爆炸伤害与二级及以上重复爆炸问题，统一遵守单次攻击最多 6 次上限且不截断主批次多杀；神掌挑战能量门槛提升至 `30`；神掌改为按实际命中敌人数计分（`110 + 命中数 × 35`，空放 0 分）。
- **流派大成与防线奖校准**：同系 3 张激活「流派小成」（`+600`），同系 3 张满级（Lv3）激活「流派大成」（`+1500` 且实际生效 `-20%` 冷却）；完好防线奖漏怪扣分由 `50` 下调至 `5`。
- **稳定性、存档与工程收口**：主循环改为时间累加器分步补回 `dt`（消除卡顿/高频点击拖慢 120s 倒计时）；排行榜过滤 `null` 与异常数值防伪造，修复历史版本标记并迁移昵称与成就；默认关闭 `window.__TJ` 暴露；单处 SVG favicon + 根目录 `favicon.ico` 消除 404。
