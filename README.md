# 天降一掌 V2.2

一款 120 秒竖屏单文件 HTML5 轻度 Roguelite 动作小游戏（HTML/CSS/JS/贴图/合成音效全部内联，零外部依赖，手机与桌面浏览器直接运行）。

## 核心特性（V2.2 实机优化版）
- **美术与视觉**：剪影皮影风双阶段幕布战场（常规暖琥珀宣纸 / 终局赤焰火山）、4 类纯黑进化怪兽剪影立绘、剪纸图腾神掌与黑洞漩涡；地面光效严格渲染在敌人下方，杜绝遮挡。
- **综合分双加成**：以综合评分为核心目标，连击倍率（1.00x–2.25x）+ 单次攻击多杀加分（3/5/8/12+ 杀）；受击不断连，空拍即断连且持续伤害不保底。
- **公平固定出兵**：每局恒定刷出 360 只敌人（普通 130 / 慢速 46 / 快速 82 / 重甲 56 / 分裂 17 / 闪避 17 / 精英 12），保证每局最高理论分上限完全一致。
- **黑洞掌概率与保底**：取消 6.0s 固定冷却，改为 Lv1 15% / Lv2 28% / Lv3 45% + PRD 伪随机保底，同屏上限 2 个（FIFO 替换并结算 Lv3 终结弹射）。
- **无痛操作心流**：限时挑战（22/48/78/102s）无缝自动触发不暂停不打断蓄力；升级三选一精简至一屏无滚动条；内置 16 组国风武侠分层合成音效与五声 BGM。
- **移动端 60 帧优化**：不透明主画布、离屏缓存光晕与贴图、空间网格与敌人对象池、低特效模式开关。

## 在线游玩 / 本地运行
